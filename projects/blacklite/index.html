BlackLite

BlackLite is a simple, dark theme for Visual Studio Code. This project does not contain any actual code, just JSON data. This extension can be found on the VS Code extensions page. It uses a completely black, simple background with bright, varied colours for the foreground. BlackLite was heavily edited from the Ayu theme. Version 1.0.0 was released in October 2025.
